NexusAI is a project that brings different AI and machine learning features into one platform.
It allows users to upload and work with documents and datasets.
Users can analyze data and understand patterns using different analysis tools.
The platform can also be used to train and evaluate machine learning models.
RAG is used to search and ask questions from uploaded documents.
AI features help users with research and understanding their data.
The project also includes model evaluation and explainability features.
The backend is built with Python and FastAPI.
The frontend uses Next.js and TypeScript with PostgreSQL for storing application data.
